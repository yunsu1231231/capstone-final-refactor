## 🖥️ 프로젝트 소개

동국대학교 캡스톤디자인 대회에서 진행한 프로젝트입니다.

기존 Node.js 기반 서비스를
React + Spring Boot 구조로 리팩토링하였으며,

회원-트레이너 매칭과 실시간 채팅 기능을
재구성 및 구현하였습니다.
